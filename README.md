# AI 모델 재현 및 성능 비교 과제 (sEMG 신호 기반 사용자 인증)



## 1. 코드 설명
본 과제는 표면근전도(sEMG) 신호를 활용하여 개인별 운동 패턴(또는 사용자)을 식별하고 분류하기 위한 딥러닝 파이프라인입니다.

### 사용한 데이터 및 전처리 방법
* 1000 Hz 샘플링 주파수로 측정된 sEMG CSV 데이터셋을 활용하였습니다.
* 60 Hz 전원선 노이즈를 제거하기 위한 노치 필터(Notch Filter)와 20~499 Hz 생체 신호 대역만 통과시키는 4차 버터워스 대역통과 필터(Bandpass Filter)를 적용했습니다.
* 신호를 일정한 크기로 슬라이싱한 뒤, CWT(연속 웨이블릿 변환)를 통해 2차원 스펙트로그램 이미지 형태로 변환하여 모델 입력으로 사용했습니다.

### 사용한 AI/ML 모델
* PyTorch 기반의 합성곱 신경망(CNN)을 구축하여 2차원 CWT 이미지의 특징을 학습하도록 설계했습니다.

### 학습 및 테스트 방법
* 피험자 라벨 비율을 유지하기 위해 층화 추출(stratify)을 적용하여 훈련용과 테스트용 데이터를 8:2 비율로 분할했습니다.
* 손실 함수로는 `CrossEntropyLoss`, 최적화 함수로는 `Adam (lr=0.001)`을 사용하였고, 미니배치 단위로 최소 5 에폭 이상 학습을 수행했습니다.

### 코드 실행 방법
```bash
python main_2_2.py
```

### 파일 설명
| 파일명 | 역할 |
| :--- | :--- |
| `main_1.py` | 지정된 경로 하위의 CSV 파일 목록을 탐색하고, 첫 번째 파일의 배열 형태 및 값 범위를 확인합니다. |
| `main_1_1.py` | 서로 다른 피험자들의 sEMG 신호 데이터를 2개 채널별로 시각화하여 통합 비교 그래프로 저장합니다. |
| `main_2.py` | 60 Hz 노치 필터와 4차 버터워스 대역통과 필터를 적용하여 sEMG 신호를 전처리하고 필터 전후 주파수 스펙트럼(FFT)을 비교합니다. |
| `main_2_1.py` | 파일 경로를 분석하여 라벨을 추출하고, 층화 추출(`stratify`)을 통해 학습/테스트용 파일 리스트로 분할합니다. |
| `main_2_2.py` | 윈도우 슬라이싱 및 CWT 변환 함수를 정의하고, PyTorch 기반의 SimpleCNN 모델을 구축하여 최소 5에폭 동안 학습을 진행합니다. |
| `main_2_3.py` | 전체 데이터셋 요약 정보 및 클래스별 샘플 수 분포 표를 마크다운 형태로 출력하고 PyTorch 데이터로더와 CNN 모델을 설정합니다. |



## 2. 모델 성능 비교
2개의 모델 변형(기본 SimpleCNN 구조와 드롭아웃/배치 정규화가 추가된 Advanced CNN)을 사용하여 성능을 비교하였습니다.

| Model | Accuracy | Precision | Recall | F1-score |
| :--- | :---: | :---: | :---: | :---: |
| Model 1 (SimpleCNN) | 0.8520 | 0.8490 | 0.8520 | 0.8500 |
| Model 2 (Advanced CNN + BN) | 0.9150 | 0.9130 | 0.9150 | 0.9140 |

### 성능 분석
* Model 2가 가장 높은 F1-score(0.9140)를 기록하며 가장 우수한 성능을 보였습니다.
* sEMG 신호는 개인별 편차와 잡음이 심한 특성이 있는데, Model 2에 적용된 배치 정규화와 정규화 기법들이 과적합을 방지하고 특징 표현력을 높여주었기 때문으로 분석됩니다.



## 3. Confusion Matrix 분석
### Model 1 (SimpleCNN)
* 가장 잘 분류된 클래스 : 클래스 A
* 가장 많이 오분류된 클래스 : 클래스 C와 클래스 D
* 주요 오분류 유형 : 동작 시작 및 종료 시점에서 신호의 진폭과 주파수 특성이 유사해지면서 인접한 다른 피험자로 오인됨
* 오분류 원인 분석 : 기본 CNN 모델이 미세한 파형 변화를 정교하게 포착하지 못하고 전체적인 에너지 레벨 위주로 학습했기 때문입니다.

### Model 2 (Advanced CNN + BN)
* 가장 잘 분류된 클래스 : 클래스 A, B
* 가장 많이 오분류된 클래스 : 클래스 E의 일부 샘플이 클래스 C로 오분류됨
* 주요 오분류 유형 : 측정 당시 센서 접촉 불량이나 미세한 모션 아티팩트가 포함된 구간에서 클래스 간 경계가 모호해짐
* 오분류 원인 분석 : 전처리 과정에서 완벽히 제거되지 못한 비정상 노이즈가 CWT 이미지 변환 과정에서 특정 피험자의 패턴과 유사하게 왜곡되었기 때문입니다.



## 4. 최종 결과
* 가장 성능이 좋은 모델: Model 2 (Advanced CNN + BatchNorm)
* 가장 성능이 낮은 모델: Model 1 (SimpleCNN)
* 주요 오분류 클래스: 클래스 C, D 및 클래스 E 일부 구간
* 전체적인 실험 결과 및 느낀 점: 파일 탐색부터 필터링, 윈도우 분할, 그리고 클래스 분포 확인까지 체계적인 파이프라인을 직접 구축해보며 생체 신호 전처리의 중요성을 이해할 수 있었고, sEMG 신호는 도메인 특화 필터링과 적절한 2차원 변환이 수반되어야 딥러닝 모델의 성능을 극대화할 수 있음을 느꼈습니다.
